Tampermonkey 使用说明

如何安装脚本
  1. 先安装 Tampermonkey。
  2. 在上方找到需要的脚本，点击“立即安装”。
  3. 在 Tampermonkey 安装页确认后点击“安装”。
  4. 打开对应业务页面并刷新即可生效。
如何检查更新

打开 Tampermonkey 管理面板，点击“检查用户脚本更新”。 脚本通过固定 @updateURL 比较远程与本地 @version， 有新版时再通过 @downloadURL 获取更新。

新版刚发布但暂时没有检测到

请先等待 GitHub Actions 与 Cloudflare Pages 部署完成。 如需立即更新，可以重新点击本页“立即安装”覆盖更新。
