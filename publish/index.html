使用与更新说明

如何安装脚本
  1. 先在上方安装与你浏览器对应的 Tampermonkey 正式版。
  2. 返回本页，在脚本列表中点击“立即安装”。
  3. Tampermonkey 打开安装页面后，确认脚本名称并点击“安装”。
  4. 打开脚本对应的网站并刷新页面即可使用。
如何检查脚本更新

打开 Tampermonkey 管理面板，点击“检查用户脚本更新”。 脚本会通过固定的 @updateURL 比较远程和本地 @version； 发现新版后通过 @downloadURL 获取更新。

新版刚发布但暂时没有检测到

请先等待 GitHub Actions 与 Cloudflare Pages 部署完成。 如果希望立即更新，也可以重新点击对应脚本的“立即安装”按钮覆盖安装。
